# Opportunités

Créez un répertoire par opportunité, par exemple `organisation-role/`. Une opportunité peut contenir plusieurs entretiens, simulations, débriefs et améliorations de préparation. N'ajoutez que les fichiers utiles : offre, analyse, CV ciblé, lettre, fiche de préparation et retours d'entretien. Évitez de créer de nombreux fichiers vides.
