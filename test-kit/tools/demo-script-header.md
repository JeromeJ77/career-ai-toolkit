# Script de démo — My Career Workspace v{version}

Généré par le build à partir de `test-kit/scenario.md` : seules les étapes `[demo]` sont conservées, réduites à ce qu'il faut faire et dire. Les résultats attendus et le détail des tests sont dans le scénario maître. Ne modifiez pas ce fichier ; modifiez le scénario.

## Avant de commencer

- Extraire le workspace **hors du dépôt**, jamais dans un workspace personnel, par exemple dans `C:\Temp\`, et suffixer son répertoire `-demo` ou `-test` suivi de la date du jour (`my-career-workspace-demo-26-10-03`) ; garder les workspaces des passes précédentes pour pouvoir comparer. Les fichiers viennent du ZIP du kit (`sources/profile/`, `sources/opportunities/`) ; les joindre à la conversation par glisser-déposer. Quand une destination est indiquée, elle est relative à la racine du workspace.
- Parler **au nom de Nadia Berkani**, la candidate fictive (motivations et points faibles : `sources/profile/notes-complementaires-carriere.md`).
- **Conversation** : « nouvelle » = fermer la conversation en cours et en ouvrir une autre dans le même workspace ; « suite de Dx » = rester dans la même.
- `[manual]` : manipulation hors conversation.
