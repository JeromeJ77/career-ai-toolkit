# Mode standalone

Copiez le contenu de `interview-coach-standalone.md` dans les instructions d'un assistant ou d'un projet IA, ou utilisez-le comme premier message d'une conversation.

Ajoutez comme sources permanentes, selon les capacités de la plateforme : CV, dossier professionnel, certifications, portfolio ou bilan de compétences. Pour chaque opportunité, joignez l'offre et la lettre éventuelle.

Les limites de persistance et de génération de fichiers sont rappelées dans le fichier. Un formulaire de retour pilote est fourni séparément dans la release.
