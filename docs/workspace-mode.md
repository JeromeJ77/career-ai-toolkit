# Workspace mode

Extract the built workspace ZIP outside the toolkit repository and open its root in a file-aware AI tool. Read `README.fr.md`, configure the profile language, add authorized sources, initialize the professional profile, then create one folder per opportunity. Keep the workspace private.

Use one assistant conversation per opportunity when possible. Keep the same
conversation for successive interview rounds, simulations, debriefs and
preparation improvements for that opportunity. If the conversation becomes too
long, start a new one by pointing the assistant to the relevant opportunity
folder and the latest files.
