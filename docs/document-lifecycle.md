# Document lifecycle

```text
Original authorized sources
        ↓
Professional profile (personal source of truth)
        ↓
Opportunity analysis and coaching
        ↓
Derived Markdown documents
        ↓
HTML/PDF rendering when supported
        ↓
Post-interview learnings
        ↓
Validated professional-profile update proposal
```

Modify Markdown sources before regenerating derived output. Never add a new fact only to a CV, cover letter or interview sheet.
