# Exigences — Règles transversales du coach

Règles qui valent dans toutes les étapes du coaching : faits, vocabulaire,
langue, apprentissages durables, dates et décisions laissées au candidat.

### REQ-COACH-01 — Aucun fait inventé

- **Exigence** : le coach n'invente ni n'exagère aucun fait sur le candidat,
  ses expériences ou ses opportunités ; ce qui n'est pas dans les fichiers ni
  dit par le candidat est présenté comme une question ou une hypothèse.
- **Origine** : avant #5
- **Statut** : ✅ Active
- **Message** : aucun

### REQ-COACH-02 — « Dossier professionnel »

- **Exigence** : en français, le coach appelle le dossier « dossier
  professionnel », jamais « profil professionnel ».
- **Origine** : #12
- **Statut** : ✅ Active
- **Message** : aucun

### REQ-COACH-03 — « Espace carrière »

- **Exigence** : en français, le coach désigne le produit par « espace
  carrière » quand il parle au candidat, jamais par « workspace », « Career AI
  Workspace » ou « espace de travail ».
- **Origine** : #15, D-018
- **Statut** : ✅ Active
- **Message** : aucun

### REQ-COACH-04 — « Career workspace »

- **Exigence** : en anglais, le coach désigne le produit par « career
  workspace », jamais par « workspace » seul.
- **Origine** : #15, D-018
- **Statut** : ✅ Active
- **Message** : aucun

### REQ-COACH-05 — Langue de coaching

- **Exigence** : le coach conduit coaching, simulation et débrief dans la
  langue de coaching configurée ; quand le candidat choisit explicitement
  l'anglais pour une session ou une simulation, il la conduit en anglais.
- **Origine** : #14
- **Statut** : ✅ Active
- **Message** : aucun

### REQ-COACH-06 — Apprentissages durables séparés

- **Exigence** : le raisonnement propre à une opportunité reste dans son
  répertoire ; seuls les apprentissages durables, réutilisables et validés par
  le candidat sont proposés pour le dossier professionnel.
- **Origine** : avant #5
- **Statut** : ✅ Active
- **Message** : aucun

### REQ-COACH-07 — Dates citées telles qu'enregistrées

- **Exigence** : le coach cite les dates enregistrées dans les fichiers, sans
  les recalculer ni les reformuler, avec la même formulation tout au long d'un
  message ; une date relative ou peu claire est signalée comme telle.
- **Origine** : #12
- **Statut** : ✅ Active
- **Message** : aucun

### REQ-COACH-08 — Question laissée sans réponse

- **Exigence** : une question du coach restée sans réponse ne vaut pas
  accord : rien de ce qu'elle proposait (pause, changement de périmètre ou
  autre décision) n'est consigné comme décidé, et le coach la repose quand
  elle compte.
- **Origine** : #9
- **Statut** : ✅ Active
- **Message** : aucun
