# Exigences — Sources du dossier

Dépôt et transcription des sources du dossier professionnel sous
`data/profile/sources/`, et registre des références externes. Les règles de
transcription (REQ-SRC-03 à REQ-SRC-08) valent aussi pour les originaux rangés
dans le `sources/` d'une opportunité.

### REQ-SRC-01 — Trois façons de fournir les sources

- **Exigence** : quand des sources sont nécessaires et qu'aucune n'a été
  fournie, le coach indique les trois façons de le faire : les copier dans le
  bon sous-répertoire de `data/profile/sources/` et le dire, les joindre à la
  conversation, ou coller leur texte. Il ne demande pas au candidat de
  connaître l'arborescence et ne lance pas de long questionnaire avant
  d'avoir les documents.
- **Origine** : #12
- **Statut** : ✅ Active
- **Message** : contenu requis

### REQ-SRC-02 — Pièce jointe rangée au bon endroit

- **Exigence** : pour un fichier joint à la conversation, le coach range une
  copie inchangée, sous son nom d'origine, dans le sous-répertoire
  correspondant (CV et export LinkedIn dans `historical-resumes/`, certificat
  dans `certifications/`, notes personnelles dans `coaching-notes/`) et dit où
  il l'a rangée ; si la catégorie n'est pas claire, il demande.
- **Origine** : #12
- **Statut** : ✅ Active
- **Message** : contenu requis

### REQ-SRC-03 — Transcription Markdown à côté de l'original

- **Exigence** : chaque source qui n'est ni du Markdown ni du texte brut (PDF,
  DOCX, image, export…) reçoit une transcription fidèle `<même-nom>.md` dans le
  même répertoire, qui commence par un en-tête court : nom d'origine, date de
  transcription et limites éventuelles.
- **Origine** : #5, D-011
- **Statut** : ✅ Active
- **Message** : aucun

### REQ-SRC-04 — Original inchangé

- **Exigence** : l'original d'une source n'est jamais modifié, déplacé,
  renommé ni supprimé ; la transcription en est dérivée.
- **Origine** : #5, D-011
- **Statut** : ✅ Active
- **Message** : aucun

### REQ-SRC-05 — Pas de transcription d'une source déjà en texte

- **Exigence** : une source déjà en Markdown ou en texte brut ne reçoit pas de
  transcription.
- **Origine** : #5, D-011
- **Statut** : ✅ Active
- **Message** : aucun

### REQ-SRC-06 — Passages illisibles marqués

- **Exigence** : la transcription marque explicitement les passages ou
  caractères illisibles, tronqués ou ambigus (par exemple `[illisible]`) au
  lieu de les deviner ou de les rétablir, n'ajoute aucun fait, et cite ces
  limites dans son en-tête.
- **Origine** : #5, D-011
- **Statut** : ✅ Active
- **Message** : aucun

### REQ-SRC-07 — Transcription existante jamais écrasée

- **Exigence** : une transcription existante n'est jamais réécrite ; si
  l'original semble avoir changé, le coach le signale et propose une nouvelle
  transcription datée.
- **Origine** : #5, D-011
- **Statut** : ✅ Active
- **Message** : aucun

### REQ-SRC-08 — Source très volumineuse

- **Exigence** : avant de transcrire une source très volumineuse (plusieurs
  dizaines de pages, ou un lot important de fichiers), le coach en indique la
  taille, demande confirmation et propose de ne transcrire que les parties
  utiles ; il ne transcrit qu'après l'accord. Une source de taille normale est
  transcrite sans demande.
- **Origine** : #5, D-011
- **Statut** : ✅ Active
- **Message** : contenu requis

### REQ-SRC-09 — Références externes notées

- **Exigence** : quand une source fournie par le candidat contient une
  référence publique le concernant (URL de profil LinkedIn, GitHub,
  portfolio…), le coach l'inscrit dans
  `data/profile/sources/external-references.md` avec le fichier source, sans
  date de vérification et sans prétendre avoir ouvert le lien, et le dit au
  candidat en une phrase courte.
- **Origine** : #5
- **Statut** : ✅ Active
- **Message** : contenu requis

### REQ-SRC-10 — Aucune référence dupliquée

- **Exigence** : une référence déjà présente dans `external-references.md`
  n'est pas ajoutée une seconde fois, y compris quand la source est relue.
- **Origine** : #5
- **Statut** : ✅ Active
- **Message** : aucun

### REQ-SRC-11 — Réimport complet

- **Exigence** : à la demande d'un réimport complet, le coach repart des
  sources (transcriptions comprises) et reconstruit le dossier professionnel
  par le workflow validé, sans rien y écrire avant validation.
- **Origine** : #5
- **Statut** : ✅ Active
- **Message** : aucun
