# Standalone mode

The standalone mode prioritizes immediate use in web assistants and project-based AI tools. It expects the user to provide the relevant profile and opportunity files. It cannot guarantee persistent file updates, cross-conversation memory, PDF generation, or automatic opportunity organization.

Use one web-assistant conversation per opportunity when possible. This helps
keep the job description, interview rounds, simulations and debriefs together
without mixing them with another application. If you must start a new
conversation, attach or paste the latest profile, opportunity and preparation
files again.

## Simulation depths and early stop

The coach offers three simulation depths: Court (short, about 10-15 minutes
and 4-6 questions), Standard (about 25-30 minutes and 8-10 questions, the
default) and Approfondi (deep, about 45-60 minutes and 12-15 questions). Write
« stop », « arrête la simulation », « arrêtons l'interview » or « end the
simulation » at any time to end a simulation; if your intent is unclear, the
coach asks for confirmation. Pausing is not supported yet. The coach leaves the interviewer role
and debriefs the questions already played. You can then work on a priority or
start a new simulation, at the same or another depth.
