# Standalone mode

The standalone mode prioritizes immediate use in web assistants and project-based AI tools. It expects the user to provide the relevant profile and opportunity files. It cannot guarantee persistent file updates, cross-conversation memory, PDF generation, or automatic opportunity organization.

Use one web-assistant conversation per opportunity when possible. This helps
keep the job description, interview rounds, simulations and debriefs together
without mixing them with another application. If you must start a new
conversation, attach or paste the latest profile, opportunity and preparation
files again.
