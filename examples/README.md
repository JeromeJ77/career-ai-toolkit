# Exemples

Ce répertoire montre, à titre illustratif, à quoi ressemble la partie `data/` d'un workspace après utilisation du coach. Tout y est fictif.

## `fictitious-developer/data/`

Résultat d'un déroulé du scénario maître du kit de test (`test-kit/scenario.md`) sur les données de la candidate fictive Nadia Berkani, développeuse backend senior. Il reproduit uniquement l'arborescence `data/` du workspace : dossier professionnel et ses sources transcrites, opportunités avec leurs entretiens, simulations et débriefs, états courants.

Il est produit **à la demande** par copie depuis un workspace de test (étape F2 du scénario), relu, puis commité. Il n'est pas régénéré à chaque build et peut être légèrement en retard sur le comportement courant du coach ; le kit de test et le scénario maître font foi.

Ce répertoire n'est jamais inclus dans le ZIP du workspace distribué.
