# Sources professionnelles

Ce répertoire contient les documents utilisés pour constituer et vérifier le dossier professionnel. Le fichier consolidé de référence est `../professional-profile.md`.

## Principes

- Conserver ici les documents originaux ou de référence ; le coach ne les modifie jamais.
- Le coach transcrit chaque document (PDF, DOCX, image, export) en un fichier `.md` de même nom dans le même répertoire, pour s'appuyer ensuite sur ce fichier plutôt que sur l'original. Vous n'avez pas à le faire vous-même. Pour un document très volumineux, le coach vous demande confirmation avant de le transcrire.
- Résumer les informations utiles dans le dossier professionnel : le coach vous les propose et ne les applique qu'après votre validation.
- Signaler les informations anciennes ou potentiellement obsolètes.
- Anonymiser les données confidentielles d'un employeur, client ou collègue.
- Ne pas ajouter de document que vous n'êtes pas autorisé à conserver.
- Utiliser des noms de fichiers explicites et, si utile, datés.

## Répertoires

- `historical-resumes/` : anciennes versions de CV.
- `certifications/` : certificats, badges et résultats.
- `skills-assessments/` : bilans et portefeuilles de compétences.
- `coaching-notes/` : notes personnelles ou issues d'un coaching.
- `recommendations/` : recommandations et témoignages autorisés.
- `evaluations/` : évaluations que vous êtes autorisé à conserver.
- `portfolios/` : réalisations, publications et références publiques.
- `external-references.md` : liens publics vers LinkedIn, GitHub ou un portfolio. Le coach y consigne les liens trouvés dans les sources que vous fournissez (par exemple l'export PDF de LinkedIn) et vous l'indique ; il ne prétend jamais avoir consulté un lien.

## Confidentialité

Avant d'ajouter un fichier, vérifiez qu'il vous appartient ou que vous êtes autorisé à le conserver, qu'il ne contient pas de secret commercial, de données personnelles inutiles de tiers ou de contenu contraire aux politiques applicables.
