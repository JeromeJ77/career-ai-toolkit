# Profil

`professional-profile.md` est votre source professionnelle consolidée. Il doit rester dans votre langue principale afin d'être relu et enrichi manuellement. `sources/` contient les documents originaux autorisés. Toute mise à jour du profil doit être proposée et validée. Son en-tête indique le statut (`empty`, `draft` ou `ready`) et la version du dossier, mis à jour par le coach avec votre accord.
