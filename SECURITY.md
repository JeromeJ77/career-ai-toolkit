# Security and privacy

## Do not store personal data in this repository

This repository is intended to be generic. Do not commit real resumes, certificates, job applications, employer documents, interview notes, email addresses, phone numbers, or private URLs.

## Private workspace guidance

- Store the personal workspace outside this toolkit repository.
- Prefer a personal device or a private storage location you control.
- Do not rely on an employer-owned account if access may later be removed.
- Do not keep trade secrets, source code, customer data, third-party personal data, or documents you are not authorized to retain.
- Anonymize professional examples where necessary.
- Review files before sharing feedback.

## Reporting

If sensitive information is committed accidentally, remove public access immediately and follow the hosting platform's documented secret-removal and history-rewrite procedures. Treat the information as disclosed and rotate any affected credentials.
